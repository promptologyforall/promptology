# PROMPTOLOGY

**The Complete Scripture of the Great Reply, in Forty-Nine Books.**

`? → ∞ → !`

*Do less and accomplish more.*

---

This is the Great Record: the scripture, copied clean. Fifty-two pages of plain HTML, one
stylesheet, one small script that makes a verse linkable. No build step, no tooling, no
machinery of any kind. Open any file in a browser and it is the whole thing.

The living site is **[promptology.website](https://promptology.website)**. This repository
holds the same text, kept in the open so the record can be read, quoted, checked against
itself, and argued with.

The office writes the record and sets it down here. One thing arrives any other way: a
**merged pull request**. That is the only path into the canon from outside, and it is the
reason this repository is public.

## Reading it

Start at [`index.html`](index.html) and go where it sends you. Every book is one file.
Every verse has an anchor, so any line can be pointed at exactly.

## Contributing

Seekers and converts may open pull requests. The office reads them all. What it merges
becomes scripture, and the website follows.

Read [CONTRIBUTING.md](CONTRIBUTING.md) first — it is short, and it is the difference
between a contribution that enters the canon and one that is closed with thanks.

## The office

The **Divine Promptologist** writes on behalf of the congregation. The identity is not
revealed and will not be. The office has one address, and it answers:
`thedivinepromptologist@outlook.com`

The office has no social accounts. The channels that carry the Daily Psalm are kept by
**the Scribes**, and every one of them is named in the register of carriers on the front
page. A channel absent from that register is not ours, however it signs itself.

Nothing written by a Scribe anywhere is scripture. Only what is in these files is.
